# Отличия от оригинала CS 1.6

Цель проекта — точный клон механик CS 1.6. Этот файл фиксирует места, где мы **намеренно
или вынужденно** расходимся с оригиналом, чтобы не принять расхождение за баг. Всё, чего нет
в этом списке, стремимся делать как в оригинале.

Условные обозначения: 🔸 намеренно иначе · 🔹 приближение (хотим как в оригинале, но реализовано
упрощённо) · 🔜 ещё не реализовано / вне рамок.

## Намеренно иначе

- 🔸 **Следы ножа — процедурные.** Декали от ножа рисуются процедурно (`_makeSlashTexture`,
  `_drawTaperedCut` в `src/effects.js`), а не берутся из оригинальных спрайтов. Следы пуль —
  из оригинальных PNG (`decals/`).
- 🔸 **Присед без «подскока».** Переход присед/вставание у нас плавный и аналитический
  (origin опускается на `18·duckAmount`, поза слёрпится). В оригинале при коротком нажатии
  приседа бывает лёгкий подскок — судя по всему, артефакт старого движка. Пока сделали «идеально»;
  возможно, вернём оригинальное поведение позже (под вопросом).

## Приближения (хотим как в оригинале)

- 🔹 **Отдача и разброс — процедурные.** M4 — процедурный T-паттерн (`recoilProc`, KickBack со
  случайной сменой стороны), USP — вертикальный `recoilKick` + растущий конус разброса
  (`src/weapons.js`). Это приближение «на глаз», а не точные seed-таблицы отдачи оригинала.
- 🔹 **Верхний слой анимации от 3-го лица (прицел/стрельба).** `ref_aim_*` хранит 3×3 грид
  (рыскание × тангаж, 9 блендов). Рыскание корпуса мы делаем поворотом всей модели, поэтому из грида
  берём только **столбец центрального рыскания [1,4,7]** (3 бленда по тангажу) и интерполируем по
  взгляду вверх/вниз. Различие в реализации жеста выстрела:
  - **Пушки:** хранится только средний бленд выстрела/перезарядки, кладётся **аддитивно** поверх
    наклонённой позы прицела (малый «кик» от тангажа почти не зависит — визуально близко к оригиналу).
  - **Нож:** взмах хранится в **3 блендах по тангажу** (низ/уровень/верх) и интерполируется по
    взгляду, играется абсолютно — режет туда, куда смотришь. Аддитива для большого замаха не годится.
  Оригинал хранит полные 9 блендов для всего; мы сократили ради размера файла. Анимация ног и переход
  присед↔стойка считаются через кватернионный slerp, как в движке.

## Третье лицо (целиком — наш инструмент)

- 🔸 **Вид от 3-го лица — режим для отладки анимаций**, а не штатный геймплейный вид. Чейз-камера
  с орбитой на стрелках (`V` — переключение). Сделан, чтобы смотреть на модель игрока и оружие.
- 🔹 **Что в нём верно как в оригинале:** мгновенная смена `p_`-модели без жеста (своей анимации
  смены оружия у мировой модели нет); один жест атаки ножом `ref_shoot_knife` на ЛКМ и ПКМ;
  двухслойная схема «ноги = походка, верх = прицел/стрельба».
- 🔹 **Gait yaw + backpedal** (`StudioProcessGait`): торс держит прицел, ноги доворачиваются к
  направлению движения с ограничением скрутки; при движении назад (>120°) ноги разворачиваются
  ~на прицел, а цикл шага играет в реверс (пятение). Реализация упрощённая: торс жёстко на прицеле
  (корень=прицел, таз отнесён к слою прицела), скрутка идёт на ноги — видимый результат как в
  оригинале, но механизм не байт-в-байт движковый (там — bone-controllers + gait-секвенция).
- 🔹 **Освещение модели по карте** (как `R_LightPoint`): трассой вниз берём запечённый свет
  (вершинные цвета карты) под игроком и тонируем материал модели/оружия — в тени темнее, на свету
  светлее. Приближение: усредняем цвет грани пола (не билинейный лайтмап-сэмпл), направленная
  компонента — фиксированная (не из карты).
- 🔹 **Вспышка дула в 3-м лице** — как в оригинале (вспышку чужих стволов видно): additive-спрайт на
  дульной кости `flash` `p_`-модели. В 1-м лице — свой вариант (в пространстве вьюмодели).
- 🔸 **Гильзы от модели в 3-м лице — наша добавка.** В оригинале латунь от мировой модели по сути
  не вылетает (видно вспышку, не гильзы). Мы эжектим гильзу из ствола модели (от кости кисти) —
  это отсебятина по эффекту, но выглядит круто, **оставляем намеренно**.

## Ещё не реализовано / вне рамок

- 🔜 **Модели игрока.** Сконвертированы CT `gign` и T `leet`/`terror` (+ старая `urban`). Модель в
  рантайме выбирается в меню класса (`playerModelName` в `src/player.js`), грузится после выбора.
- 🔜 **`p_`-модели оружия** есть только для M4A1, USP и ножа.
- 🔹 **Выбор команды / класса (old style).** После «Начать игру» — числовое меню: команда (T / CT /
  авто) → класс (доступные модели). Выбор делает `setTeam` (спаун на точке команды) + грузит модель.
  Только две команды, классы = что сконвертировано. `src/game.js`.
- 🔹 **Закупка оружия.** Числовое меню по клавише **B** — те же категории и **комбинации клавиш, что в
  оригинале** (B → категория → номер; 6/7 — патроны основного/пистолета, 8 — снаряжение). Меню
  показывает только оружие **своей команды**, перенумерованное 1..N — как настоящий buy-меню; ограничения
  по командам канонические CS (M4A1/FAMAS/AUG/TMP/SG-550/Five-SeveN — CT; AK/Galil/SG-552/MAC-10/G3SG1/
  Elites — T; пистолеты/дробовики/MP5/UMP/P90/Scout/AWP/M249 — оба). Цены сверены с ReGameDLL
  (`weapontype.h`). **Реально стреляют (18):** нож; винтовки M4A1 / AK-47 / Galil / FAMAS / AUG / SG-552;
  ПП MP5 / TMP / MAC-10 / UMP45 / P90; пулемёт M249; пистолеты USP / Glock-18 / Desert Eagle / P228 /
  Five-SeveN (урон/спад/боезапас/скорострельность сверены с ReGameDLL). **Ещё не подключены** (нужны
  новые механики): дробовики M3 / XM1014 (пеллеты), снайперки Scout / AWP / SG-550 / G3SG1 (зум+болт),
  Dual Elites (dual-wield); FAMAS/Glock — пока без бёрст-режима. Слоты: 1 — основное, 2 — пистолет,
  3 — нож; покупка нового вытесняет старое в слоте (как в CS). Деньги для теста **$16000**, покупка
  **только в зоне закупки** своей команды (`func_buyzone` из BSP). Брони у игрока пока нет.
  Приближения: отдача процедурная (не seed-таблицы CS). **Вспышка дула и вылет гильзы** позиционируются
  строго по оригинальным attachment'ам из MDL каждого ствола: attachment 0 = дуло, attachment 1 = порт
  гильзы (кость + смещение; совпадают с ручными значениями M4/USP). Никакого угадывания «по кончику
  меша» или «из центра» — если у ствола нет нужного attachment'а, эффект **не рисуется** (пишем warning
  в консоль), а не ставится в выдуманное место. Спрайт вспышки по типу: винтовки/ПП/пулемёт — большой
  `muzzleflash3` (как у M4 без глушителя), пистолеты — малый `muzzleflash2`, глушитель — малый. От 3-го
  лица оружие в руках + вспышка работают для всех подключённых (грузятся все `p_*`-модели).
  `src/game.js`, `src/weapons.js`, `src/player.js`.
- 🔜 **Остального геймплея нет** — раунды, боты, бомба/флаги, урон по игроку, звук.
- 🔸 **Мишени-манекены (T `leet` — Elite Crew, 3 шт.)** у спауна CT — наш отладочный объект для проверки попаданий,
  пробития и анимации смерти: стоят в idle рядом/уступом (чтобы ловить сквозное пробитие), через
  несколько секунд после смерти респавнятся. Манекены привязаны к первой CT-точке спауна. Это
  тест-инструмент, не геймплей.
- 🔹 **Точки спауна и угол взгляда — из BSP.** Все `info_player_start` (CT) и `info_player_deathmatch`
  (T) извлекаются `bsp_phys.py` с реальным yaw (средний компонент `"angles"`), по 20 на команду.
  Респаун: `pickSpawn(team)` ставит игрока на случайную точку команды и поворачивает на её фиксированный
  угол (в оригинале точки раздаются последовательно на старте раунда — у нас случайно, ради показа
  разных углов). Прежний костыль «+180°» убран (он компенсировал баг чтения угла — он читался как 0).
- 🔹 **Пробитие пулей (penetration).** Один выстрел проходит сквозь манекены по лучу по очереди, теряя
  по `PEN_MULT` (0.6) урона на каждое тело; стена по тому же лучу блокирует всё, что за ней. Это
  упрощение CS-пробития (там — бюджет «мощности» по толщине/материалу преград); у нас фиксированный
  множитель и преграда = первая сплошная стена BSP. Нож бьёт только ближайшего.
- 🔹 **Урон по манекену — по модели CS 1.6.** 100 HP + 100 брони (кевлар, без шлема). Урон оружия:
  M4A1 32 (33 с глушителем) / USP 34 (30 с глушителем) на пулю, нож 20 (ЛКМ) / 65 (ПКМ), бэкстаб ×3.
  Значения и формулы сверены с ReGameDLL_CS. Учитываются:
  - **спад по дистанции:** `damage *= rangeMod^(dist/500)` (M4 0.97, USP 0.79) — на длинной дистанции
    режет урон, как в оригинале;
  - **множители по зонам (hitgroup):** голова ×4, грудь/руки ×1, живот ×1.25, ноги ×0.75. Хитбоксы —
    **капсулы по костям** (как в CS): сегмент между двумя костями + радиус, кости ищутся по имени
    (`Bip01 Pelvis/Spine1/Neck/Head`, `… UpperArm/Forearm/Hand`, `… Thigh/Calf/Foot`). Позиции костей
    берутся из bind-позы (`computeBoneWorlds`) и переводятся в мир, поэтому капсулы повторяют реальную
    позу модели (наклон, вынесенные руки). Выстрел — ближайшая капсула по лучу (ray–segment). Есть
    отладочная галка **«Показать хитбоксы»** — рисует капсулы каркасом. Капсулы пересчитываются каждый
    кадр по текущей позе (берут кости, уже посчитанные для скиннинга), поэтому следуют анимации.
    Приближение: радиусы капсул заданы вручную (не из меша);
  - **броня:** формула CS (`ARMOR_RATIO/BONUS = 0.5`) — кевлар поглощает только корпус/живот; голова и
    ноги идут прямо в HP (шлема нет).
  При смертельном попадании играется **анимация смерти по зоне** (голова → `head`, живот → `gutshot`,
  иначе `death1/2/3`), при несмертельном — **флинч** (`head_flinch`/`gut_flinch`, по центральному бленду).
  HUD цели (HP/броня + последний хит с зоной) — сверху по центру; это наш индикатор для теста, в
  оригинале такого «здоровья врага» на экране нет.
  - 🔹 **Кровь** — в точке попадания, количество масштабируется по нанесённому HP-урону (хедшот без
    брони — сильный фонтан, корпус под бронёй — почти нет). Два режима:
    - **по умолчанию — оригинальные спрайты** `bloodspray.spr`/`blood.spr`/`blooddrop.spr` (вытащены
      `tools/extract_spr.py` из `valve/sprites`; серые в оригинале, тонируются в красный движком — у нас
      тоже тонируются). Анимированное облачко-всплеск + падающие капли.
    - **галочка «Улучшенный урон»** (по умолчанию выкл) — наш процедурный вариант: плотный мягкий
      веер капель (радиальный градиент) + туман.
    В режиме «Улучшенный урон» дополнительно ставится **кровяная декаль-брызг** на стене позади тела
    (процедурный красный сплат, `_spawnDecal('blood')`). В обычном режиме декали-лужи нет.
  - 🔹 **Нож** (свер. по ReGameDLL `wpn_knife.cpp`): swing 20, stab 65, бэкстаб ×3 (срабатывает, когда
    целишься туда же, куда смотрит цель — `dot>0.8`). Множитель зоны и броню нож **тоже** учитывает
    (бьёт через `TraceAttack(DMG_BULLET)`), т.е. удар в голову ×4.

## Что специально совпадает с оригиналом

(для контекста — это не отличия)

- Физика GoldSrc: ускорение/трение, air-accel и bhop, лестницы, присед-хулл.
- Вьюмодели и их скелетная анимация — из оригинальных MDL (M4A1/USP/нож, глушитель).
- FOV (эмуляция `allow_widescreen`), landing-punch только креном (без вертикального кивка), как в оригинале.
